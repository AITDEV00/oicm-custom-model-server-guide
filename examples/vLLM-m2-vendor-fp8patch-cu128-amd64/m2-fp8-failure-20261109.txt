compressed-tensors checkpoint uses static 128x128 block weights and dynamic
group128 activations. FP8 KV E4M3 cache was separately accepted before load.

and rank7 local range168-191.

params_dict -> name_mapped dict -> cannot find fused scale name.

BF16 w13_weight and w2_weight, and NO FP8 scale parameter slots. The
original error did not mean the sparse source scale was absent.

all 486 original ignore entries rather than quantizing shared experts/attention.
