# SGLang v0.5.18

- **Folder:** `examples/SGLang-podman-v0.5.18-cu129-amd64/`
- **Base image:** `docker.io/lmsysorg/sglang:v0.5.18-cu129`
- **Build target:** `make build-sglang-podman-0.5.18`

## Release context

- Released **August 22, 2026**; release commit `71de97b`.
- Contains **PR #33639 — Mamba branching in Unified Radix Cache with HiCache**
  and the bit-exact HiCache logprob consistency test **#34356**.
- This is the recommended engine for deploying **Qwen3.5-122B-A10B** and
  **Qwen3.6-35B-A3B** with hierarchical (L2 CPU-DRAM) KV caching.

See [startup.sh anatomy](../reference/startup.md) and
[arg_normalizer.py](../reference/arg_normalizer.md).

## Notes specific to v0.5.18

- v0.5.18 moved compiled Triton/FlashInfer/DeepGEMM/Inductor/CUDA caches under
  `SGLANG_CACHE_DIR`; the first boot after an upgrade can recompile kernels and
  be much slower than subsequent launches (an upgrade behavior, not a HiCache
  failure).
- Canonical CUDA-graph disable flags are now
  `--cuda-graph-backend-decode disabled` / `--cuda-graph-backend-prefill disabled`
  (`--disable-cuda-graph` still parses but is deprecated).
