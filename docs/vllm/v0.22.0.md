# vLLM v0.22.0

- **Folder:** `examples/vLLM-podman-0.22.0-cu129-amd64/`
- **Base image:** `docker.io/vllm/vllm-openai:v0.22.0-cu129`
- **Build target:** `make build-vllm-podman-0.22.0`

Standard vLLM serving image. `Dockerfile` sets `ARG VLLM_VERSION=0.22.0` and
reinstalls `vllm[audio]==${VLLM_VERSION}`.

See [startup.sh anatomy](../reference/startup.md) and
[arg_normalizer.py](../reference/arg_normalizer.md) for the shared behaviors.
