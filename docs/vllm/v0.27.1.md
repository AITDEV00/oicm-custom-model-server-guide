# vLLM v0.27.1

- **Folder:** `examples/vLLM-podman-0.27.1-cu129-amd64/`
- **Base image:** `docker.io/vllm/vllm-openai:v0.27.1-cu129`
- **Build target:** `make build-vllm-podman-0.27.1`

Audio-capable serving image (`vllm[audio]`) that also installs **librosa** in the
same pip layer. The Dockerfile is optimized for fast rebuilds:

- Build/health tooling (`git gcc curl`) is in its own layer, so pip-dependency
  changes don't re-run `apt-get`.
- `vllm[audio]` + `librosa` share one pip layer.
- A BuildKit `--mount=type=cache,target=/root/.cache/pip` persists pip's wheel
  cache across builds, so unchanged wheels are reused instead of re-downloaded.

`ARG VLLM_VERSION=0.27.1`.

See [startup.sh anatomy](../reference/startup.md) and
[arg_normalizer.py](../reference/arg_normalizer.md).
